Overall description: These supplementary files contain the VoBiRo 3D model assets, the Webots simulation project, and the Processing-based graphical user interface used in the study. They allow readers to inspect the robot model, run the reported simulation scenarios, and examine the implementation of interactive gait tuning.

- S1 — VoBiRo 3D model: “OBJ and MTL files defining the visual geometry and materials of the VoBiRo humanoid used in the Webots simulation.”
- S2 — Webots simulation project: “Webots worlds and controllers for the flat and h10 uneven-terrain experiments, including the fixed Default and OFAT-Optimized gait configurations and CSV data logging. Run instructions are provided in the accompanying GUIDE.”
- S3 — Processing GUI: “Processing source code and supporting assets for the interactive gait-tuning interface and UDP communication with a compatible Webots controller.”
